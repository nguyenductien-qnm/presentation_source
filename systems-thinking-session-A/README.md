# Lỗi hết rồi, sao hệ thống vẫn chết? (Session A)

- `Session-A_slides.html`: chỉ có slide (24 slide, không có demo). Phím ← → / Space, F toàn màn hình.
- `Session-A_slides-va-script.html`: slide kèm script (mỗi slide một đoạn lời nói), S ẩn/hiện script. Cuối file có 2 trang phụ lục: thời gian + hỏi đáp, và checklist trước buổi nói.
- Phân công người nói: Người 1 nói slide 1-10 và 22-23, Người 2 nói slide 11-21. Nhãn hiện ở thanh dưới và trong panel script. Đổi tên người trong `NAMES` ở đầu `build_html.py`, rồi chạy `python3 build_html.py` để build lại 2 file HTML.
- `script_session_A.md`: script dạng văn bản, bản gốc để chỉnh sửa.
- `slides-source/`: nguồn slide (deck.json + slides/*.html), 24 slide, khớp với artifact.
